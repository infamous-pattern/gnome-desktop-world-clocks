# Desktop World Clocks launch copy

## LinkedIn launch post

Coordinating across time zones should not require opening another app or doing mental arithmetic.

I’m pleased to share Desktop World Clocks, now approved and available through the official GNOME Extensions website.

It places the times that matter to you directly on the GNOME desktop. You can create up to four independent groups, show as many as 40 clocks, and customize the labels, fonts, colors, opacity, layouts, monitor placement, and backgrounds.

The extension uses the computer’s existing synchronized system time. It does not run its own NTP client, make network requests, collect telemetry, or start a permanent helper service. The approved release supports GNOME Shell 49, 50, and 51.

I led the concept, product direction, desktop testing, and maintenance. OpenAI Codex helped implement the extension, tests, documentation, and build tooling under my review. The complete source is available on GitHub.

Install it here:
https://extensions.gnome.org/extension/10916/desktop-world-clocks/

Source, documentation, and issues:
https://github.com/infamous-pattern/gnome-desktop-world-clocks

If you work across regions, I would like to hear how you arrange the clocks on your desktop and what would make the extension more useful.

## r/Linux submission

**Title:** I released Desktop World Clocks for GNOME Shell 49–51

I created Desktop World Clocks for people who want the relevant times to remain visible without opening another application. It places those clocks directly on the GNOME desktop.

The extension supports up to four independent groups with ten clocks each. Each group can have its own monitor, corner, layout, font, colors, opacity, labels, time format, and transparent, solid, or image background. It uses the existing system clock and time service; the extension itself makes no network requests and collects no telemetry.

Version 2 has been reviewed, approved, and activated on the GNOME Extensions website for GNOME Shell 49, 50, and 51:

https://extensions.gnome.org/extension/10916/desktop-world-clocks/

The project is GPL-2.0-or-later. I led the concept, product direction, desktop testing, and maintenance. OpenAI Codex assisted with implementation, tests, documentation, and build tooling under my review. Source and issue tracking are here:

https://github.com/infamous-pattern/gnome-desktop-world-clocks

I would welcome feedback from people who regularly coordinate across time zones, especially on layouts and multi-monitor use.
