# Desktop World Clocks v1.0.0

Desktop World Clocks keeps the times that matter to you visible on the GNOME desktop. The first public GitHub release corresponds to approved GNOME Extensions Version 2 and supports GNOME Shell 49, 50, and 51.

Install the reviewed release from the [GNOME Extensions website](https://extensions.gnome.org/extension/10916/desktop-world-clocks/).

## Highlights

- Up to four independent groups with ten clocks each.
- All time zones from the installed IANA database, with custom descriptions and optional abbreviations.
- Five layouts, including a right-aligned time column.
- Per-group monitor and corner placement.
- Installed GNOME fonts, font size, opacity, global or per-clock colors, and text shadow.
- Transparent, solid-color, or local-image backgrounds.
- Existing system time and synchronization service; no extension network traffic or telemetry.
- One shared timer that pauses during Overview, suspend, and full-screen use.
- Native GTK/libadwaita preferences and GPL-2.0-or-later source.

## Validation

The full automated and physical-desktop acceptance suite passed on GNOME Shell 50.4. Core suites passed on GNOME Shell 49.9 and 51.beta; image and physical-session checks remain pending on those two environments. See the repository development notes for detailed scope and limitations.

Report problems or request features through [GitHub Issues](https://github.com/infamous-pattern/gnome-desktop-world-clocks/issues).
