## Lemmy post

**Title:** I released Desktop World Clocks for GNOME Shell 49–51

My Desktop World Clocks extension was approved and is now available on the official GNOME Extensions website.

I built it because I wanted the times that matter to stay visible without opening another application or doing time-zone arithmetic. It supports up to four independent groups with ten clocks each. Each group can have its own monitor, corner, layout, labels, fonts, colors, opacity, time format, and transparent, solid-color, or image background.

It uses the computer’s existing synchronized system clock. The extension makes no network requests, collects no telemetry, and starts no permanent helper service.

Install it here:
https://extensions.gnome.org/extension/10916/desktop-world-clocks/
